Results, tables and figures for RQ1–RQ4 and RQ6 of the SwinFusion++ deepfake-detection thesis (group 9, University of the East–Manila).

**Start here for the graphs:** [`corrected_20261028_optionA/figures_clear_20261108/`](corrected_20261028_optionA/figures_clear_20261108/). These are the current, checked charts, and its README lists what changed.

|---|---|
| `corrected_20261028_optionA/` | **Current results.** Fixed-recipe comparison as principal, BO-selected as configured system, with tables, write-ups, calibration and compute. |
| `00_Shared/` | Raw statistics, protocol and decision records, literature tables. |
| `figures_recreated/`, `corrected_20261004/` | Earlier corrected versions, kept for the record. |
| `RQ1/` … `RQ6/`, `_originals_before_corrections_20261004/` | Original generated output, kept for the record. |
